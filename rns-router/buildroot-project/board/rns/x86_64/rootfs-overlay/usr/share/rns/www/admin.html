Admin security

Forgot the staff password?

There's no in-app reset — a stranger with the phone can't lock you out or reset it themselves. To recover it, run this from a root shell on the router (serial console or rns-ctl ssh on):

sh /usr/share/rns/bin/rns-ctl.sh setpass NEWPASS

Replace NEWPASS with the password you want, then sign in with it here.

Where your data lives

Every voucher, client, package and sale is kept as plain .tsv files on the router, not inside this browser:

/data/rns/database/

(vouchers.tsv, clients.tsv, packages.tsv, online-packages.tsv, payments.tsv and settings live in that folder.) The Backup data button above copies a dated snapshot to /data/rns/backups/.

Wipe everything and start fresh

This is deliberately not a button in the app — a wrong tap here would erase every voucher and sale with no undo. To erase all data:

  1. Boot the router to a root shell
  2. Create an empty purge marker: touch /data/rns/PURGE
  3. Reboot — vouchers, clients and settings are deleted, and you'll set a new password on next open

Skip step 2 and your history is kept, so the old vouchers, clients and password come back on the next boot.
